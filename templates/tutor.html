How the API call works
  1. Your question is sent via fetch() to POST /api/ask on this server.
  2. Flask validates the input (empty, length, JSON format).
  3. The server calls the Gemini API using the key stored only in .env.
  4. Gemini's answer is returned to your browser as JSON — the key never leaves the server.
